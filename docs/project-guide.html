02 / Training & provenance

From the CSV to saved pipelines.

Separate notebook history from the measured results of the current implementation.

01 · Read and deduplicate

100,500 rows × 50 columns. Remove 500 exact duplicates → 100,000 unique incidents. 29.406% have Attack_Success = 1.

02 · Define the 16-feature schema

2 categorical + 14 numeric/binary inputs. This is a domain-based reduction, not proven to be the original forest’s exact top 16. Select only these columns and the target.

03 · Split before learning transformations

80,000 training / 20,000 test rows, stratified by target, seed 42. 3,147 unique records lack detection time.

04 · Fit training preprocessing

New LR: median imputation (detection median 103 minutes), one-hot encoding and numeric/binary standardization. Existing RF: categorical encoding + numeric passthrough; its historical imputation occurred outside the saved pipeline.

05 · Fit and evaluate

The saved RF is retained. Scaled LR is fitted on training rows only. Both are scored on the same reconstructed documented test split.

06 · Persist and serve

joblib stores preprocessing plus classifier. evaluation.json records metrics, case outputs and hashes. Streamlit verifies schema and artifact/metadata consistency.

04 / Models & calculation

How a probability is calculated.

Actual trained classifiers with different assumptions. The archived HTML scoring approximation is not used.

Primary / Random Forest

150 trees learn nonlinear patterns.

Each tree follows splits to a leaf. Its class-1 probability comes from the leaf’s training-class distribution. The forest averages all 150 probabilities.

p = (p₁ + p₂ + … + p₁₅₀) / 150
max_depth = 12min_samples_leaf = 5class_weight = None

This is not simply the fraction of trees voting breach. Leaf probabilities can be fractional. Numeric scaling is unnecessary for tree split ordering.

Baseline / Logistic Regression

A weighted logit becomes a probability.

The pipeline imputes and standardizes numeric/binary inputs. It combines 22 transformed values with learned coefficients and an intercept, then applies sigmoid.

z = b + Σ βⱼxⱼ
p = 1 / (1 + e⁻ᶻ)
L2 regularizationmax_iter = 1000converged: 24 iterations

Coefficients apply to transformed inputs. They are learned from labeled examples, not assigned from forest importance.

Measured on the same holdout

A single invented case has no known outcome, so its higher score does not establish a better prediction. RF leads on most aggregate metrics in this split; LR has higher precision. Statistical significance, calibration and generalization are not established.

06 / Submission readiness

What an examiner may ask.

Prioritized improvements to make the claims match the project’s evidence.

P1

Define the prediction cutoff.

Encryption, exfiltration and final containment time may be outcomes or future information. Define a cutoff and retrain an early-warning variant using only available signals. Until then, describe this as retrospective incident classification.

P1

Execute the reduced notebook and reconcile training.

The 16-feature notebook has no stored outputs. Move its full-data median imputation into training/fold pipelines. The old script used balanced weights, while the saved forest did not; the current script matches class_weight=None. Record a clean notebook run and training lineage.

P1

Verify dataset provenance and semantics.

Stage/telemetry inconsistencies and counterintuitive defensive-control relationships need explanation. Document signal/label generation. A dataset link alone does not establish independent real enterprise incidents.

P2

Validate the small performance differences.

Add stratified training-fold CV and paired bootstrap intervals. Use chronological splits if timestamps reflect deployment and grouped splits if organizations repeat. Keep final test data out of model and threshold selection.

P2

Calibrate probabilities and select operating thresholds.

Add reliability curves and Brier evaluation, fitting calibration within training folds. Compare false-negative/false-positive costs. Current risk bands and the 0.5 classification cutoff are demonstration choices.

P2

Check feature significance and generalization.

Add held-out permutation importance, stage-only and pre-outcome baselines, and sensitivity analysis for stage, controls and timing. Check whether manual cases fall within the training distribution; toggle results are not causal effects.
