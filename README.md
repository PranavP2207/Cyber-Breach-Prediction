# Cyber Breach Prediction Across the Enterprise Kill Chain

A machine learning system that predicts whether an in-progress cyber intrusion will result in a successful breach or be contained, using only pre-breach signals such as defensive posture and kill-chain progression.

## Problem Statement

Security Operations Center (SOC) analysts face constant pressure to assess breach likelihood in real time, often relying on scattered signals and manual judgment. This project automates that assessment with a Random Forest classifier trained on 100,000 enterprise incident records, enabling faster and more consistent threat prioritization.

## Model Performance

| Metric | Score |
|---|---|
| Accuracy | 86.4% |
| F1-Score (breach class) | 0.77 |
| ROC-AUC | 0.93 |
| Training Records | 100,000 |
| Input Features | 40 |

### Kill-Chain Stage vs. Breach Rate

The strongest predictor is how far an attacker has progressed through the kill chain — the further along, the more likely the intrusion succeeds.

| Stage | Breach Rate |
|---|---|
| Reconnaissance | 4.7% |
| Initial Access | 38.6% |
| Execution | 56.1% |
| Persistence | 73.3% |
| Impact | 93.8% |

## Features

- Three-panel input form covering enterprise profile, defensive controls, and kill-chain telemetry
- Live breach-probability score generated by the trained model
- Risk classification into LOW, MEDIUM, HIGH, and CRITICAL bands
- Quick-scenario presets for one-click demos:
  - Case A: Contained attack (Reconnaissance stage, hardened defenses) → LOW risk
  - Case B: Critical breach (Impact stage, weak defenses) → CRITICAL risk
- Standalone HTML prototype for zero-install demonstrations

## Model

A Random Forest classifier (150 trees, max depth 12), trained on an 80/20 stratified split and benchmarked against a Logistic Regression baseline. Forty features spanning enterprise profile, defensive controls, and kill-chain telemetry are one-hot encoded and passed to the model, which outputs a breach probability used to assign the risk label.
